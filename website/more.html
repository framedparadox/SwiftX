More from the developer

Other small, independent tools — Windows apps, VS Code extensions, and MCP servers — built by the same developer behind SwiftX, each scratching one specific itch.

Everything here is open source. See the GitHub profile for the full list.

Windows apps

Native WinUI 3 apps that live in the tray or on the desktop edge.

DockDev

WinUI 3 · Windows 11

A floating quick-access dock of developer utilities — JSON formatting, JWT decoding, file hashing, and PII masking — with pasted content that never leaves the PC.

GitHub Microsoft Store

Anchor Dock

WinUI 3 · Windows 11

A floating dock that pins apps, files, folders, and web links to any monitor edge — snaps into place, auto-hides, and supports one dock per screen.

Website GitHub Microsoft Store

VS Code extensions

Developer-utility extensions, published to both the VS Code Marketplace and Open VSX.

VsGit

VS Code extension

A full Git client for VS Code that runs the real git binary — 173 commands across tree views, webviews, an interactive commit graph, and Source Control integration.

Marketplace Open VSX GitHub

MuleSoft AES

VS Code extension

Encrypts and decrypts MuleSoft secure configuration properties right inside VS Code. Cryptography runs locally; keys stay in VS Code's own secret storage.

Marketplace Open VSX GitHub

Certificate Utility

VS Code extension

Inspects and validates certificate artifacts, with conversion and keystore workflows plus an expiry scanner — all without leaving the editor.

Marketplace Open VSX GitHub

Developer Utility

VS Code extension

A grab-bag of day-to-day developer tools in one extension — data formatting, certificate management, and encoding/decoding.

Marketplace Open VSX GitHub

MuleSoft tooling

IDE and CI-side plugins for MuleSoft developers.

SonarQube plugin for MuleSoft

SonarQube plugin

A SonarQube plugin that analyzes MuleSoft applications, bringing Mule-specific rules into a team's existing code-quality pipeline.

GitHub

Copilot for Eclipse Anypoint

Eclipse plugin

Brings GitHub Copilot into MuleSoft's Anypoint Studio IDE, which is built on Eclipse and has no first-party Copilot support of its own.

GitHub

Agentic & MCP

Small pieces of infrastructure for AI agents and the Model Context Protocol.

mcp-secure-remote

MCP proxy

A stdio ↔ remote bridge for the Model Context Protocol, secured with mutual TLS. Runs via npx or uvx with no separate install step.

npm PyPI GitHub

pr-comments

Agent skill & CLI

Agent skills and a CLI that pull pull-request review comments into a CSV and a local review dashboard, so an agent can act on reviewer feedback directly.

npm PyPI GitHub
